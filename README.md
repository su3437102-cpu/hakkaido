# 北海道行程 · 局域网网站项目

这是在你电脑上运行的局域网网站。同一 Wi-Fi 或有线网络里的设备可通过启动窗口显示的内网地址访问。地理地图已内置，不依赖互联网地图服务。

## Windows 启动

1. 将压缩包完整解压到一个新文件夹。
2. 双击 `启动网站.cmd`。首次需要电脑已安装 [Node.js 官网的 LTS 版](https://nodejs.org/)。项目没有 npm 依赖，无需 `npm install`。
3. 浏览器会打开本机网址。手机、平板等设备使用启动窗口显示的“同一网络”网址。
4. 保持启动窗口开启，按 `Ctrl+C` 停止网站。

例如，电脑当前内网 IP 为 `192.168.3.4`，且4312端口可用，网址就是 `http://192.168.3.4:4312/`。实际地址由电脑网卡决定；4312被占用时会自动选4313等可用端口，以启动窗口显示为准。

如 Windows 首次询问防火墙访问权限，允许“专用网络”，同一网络里的其他设备才能连接。此项目不会修改你的网络或防火墙配置。

macOS / Linux 可以在项目文件夹中运行：

```sh
node server.mjs --open
```

指定端口：

```sh
node server.mjs --port=4312 --open
```

不要直接双击 `public/index.html`；这个项目通过本地服务读取行程 JSON。若需要完全不启动服务的单文件版本，网页右上角的“下载离线包”仍可使用。

## 如何制作和更新

修改文件并保存，已经打开的页面会自动刷新，并尽量恢复当前日期、地图模式与阅读位置。

| 内容 | 文件 |
| --- | --- |
| 网页文案、原时间轴、酒店与说明 | `public/index.html` |
| 每日地图顺序、地点、餐厅及主备选 | `public/data/itinerary.json` |
| 页面样式 | `public/styles/page.css` |
| 地图及路线卡片样式 | `public/styles/map.css` |
| 局域网状态条样式 | `public/styles/lan.css` |
| 地图交互逻辑 | `public/js/map-app.js` |
| 离线底图数据 | `public/data/offline-basemap.js` |
| 离线底图绘制 | `public/js/offline-basemap.js` |
| 原机票比价页 | `public/price-monitor.html` |

`itinerary.json` 内的 `places` 是地点，`foods` 是餐厅，`days` 是每日路线，`branches` 是天气等方案。每个停靠点的 `time`、`title`、`note` 对应时间、名称与提示；`choices` 指定该餐次可选餐厅。修改 JSON 后应保持逗号和引号完整。

原时间轴与地图是两个视图。调整行程时，同时核对 `public/index.html` 的时间轴和 `itinerary.json` 的路线，避免文字与地图不一致。地图数据文件和底图绘制已分离，普通文字更新不需要修改5MB左右的底图数据。

后续继续让助手修改时，提供这个项目文件夹或其压缩包即可；不必每次从单个巨大 HTML 中拆解。

## 地图和数据

- 已保留每天路线、餐厅主备选、完成勾选，以及2月1日支笏湖冰涛祭的已选主路线。
- 地图显示、缩放、餐厅卡片与顺序图无需互联网。局域网设备仍需连接运行网站的电脑。

- 数据来源和许可见 `public/地图数据来源.txt`、`public/Leaflet-LICENSE.txt`。
